DEFECTS FOUND AND FIXED

- Player optional-chain auto-pass ignored the window timing and passed event windows (own attack Damage Step, own Summon, destruction, banishment). Fixed by reading hint_timing.
- Dummy position changes used a flat score: monsters toggled between Attack and Defense every Main Phase 2 and walls were flipped face-up. Fixed with a board-aware score.
- Dummy accepted every LP-cost prompt regardless of its LP. Fixed.
- Dummy attackers of any ATK rammed unknown set monsters. Fixed for attackers below 1600 ATK.
- The fixes exceeded the duel-core.js embedded slot by 1,093 bytes. tools/patch_embedded_web.py now compacts whitespace on literal-free lines; processed sizes are 797,018 bytes for duel-core.js (1,533 bytes of headroom) and 437,517 bytes for app.js.
